## §2 关键判据（详细设计）

- **栈机式表达式求值**：操作数 push、运算符 pop 两数算完 push 回——与 AST
  的后序遍历天然同构。类型与字段名到此彻底消失，只剩地址和数字。
- **帧布局不变量**（learn/24 修的 bug）：estimateFrameSize 必须算上"帧基 +
  形参 spill 槽"，否则最深的局部落在 rsp 之下被 pushq/callq 踩掉（症状：
  变量单独读对、参与二元表达式就错）。test_codegen_frame.cpp 断言
  「帧 N ≥ 最深 -X(%rbp)」。
- **符号拼装全部过 asmSymbol**：命名空间类的 ctor/dtor、vtable 条目都不能
  在汇编期留下 junk。★ 消费点优先用 Sema 的**回填槽**（resolvedCalleeSymbol
  等），空才退回硬拼——mangling 是有状态的，CodeGen 不知道重载后缀。
- **类对象路径**：构造升级（VarDeclStmt 走 ctorSymbol）、平凡拷贝判据
  （equals，不看穿 const 会静默退化成默认构造——stripTopCvRef 判据归一）。
- **数组与下标**（learn/42）：数组名向首元素地址退化（VarExpr/MemberExpr
  统一 leaq），IndexExpr 读与 AssignStmt 写用 SIB 寻址（leaq (%rcx,%rax,scale)）。
- **控制流降级**（learn/38、41）：for 五标签、m_loopStack 保证 continue
  落【增量步】不落条件式；?: 短路两行条件跳转；switch 比较链 + fall-through。
- **vtable/RTTI 数据段**：槽符号与定义点同源（memberMethodSymbolName 单点，
  B20）；次基类槽原样透传上游符号，真覆写才改指本类实现 + thunk。

## §3 诊断类别（异常处理）

**CodeGen 本身不产生诊断**——src/codegen/codegen.cpp 里零 `std::cout`、零 `error()`，
它只发射汇编。错误在**下游**显形：

| # | 触发情形 | 诊断文案 | 可重试 |
|---|---|---|---|
| 1 | `callq` 的目标符号没有定义（符号拼错 / static 成员漏定义 / vtable 槽错配） | 链接期 `undefined reference to '{符号}'`（src/link/linker.cpp） | 否 |
| 2 | 同一符号被定义两次（重载后缀缺失导致撞名） | 链接期 `符号重复定义: '{符号}'`（src/link/linker.cpp） | 否 |
| 3 | 可执行文件缺 `main` | 链接期 `undefined reference to 'main'（可执行文件需要 main 函数）`（src/link/linker.cpp） | 否 |
| 4 | 汇编器 `as` 失败（汇编期语法错） | `[ERROR] 汇编失败 (as 退出码 {码})`（src/driver/main.cpp） | 否 |

★ 第 1~3 条是**链接期**才响——编译期全程绿灯（历史上 B10 / B20 / B22 全是这类：
`c.f(1)` 报 `undefined reference to 'C_f'`、`symbol 'C_f_1' is already defined`）。
本模块的**单点判据**（符号拼装优先用 Sema 回填槽）就是为消灭这一类而设。

## §4 Out of Scope（本模块不做的事）

- **不生成 LLVM IR**：直接吐 .s，没有中间层（对照 clang 的 CGExpr → LLVM IR → SelectionDAG → AsmPrinter 三层）。
- **汇编器不是自研**：借系统 `as`（**链接器**才是自研的，见 07 域）。
- **不做 PIE**：加载地址固定（这是链接器的取舍，见 07 域）。
- **`&&` / `||` 不做短路求值**：直接降级成 `andq` / `orq`（src/codegen/codegen.cpp 的 BinaryExpr 分派），放弃了"左值为假则不算右值"。★ `?:` **是**短路的（两行条件跳转，跳过落选支）。真 `&&`/`||` 的形状等价于两个嵌套 if。
- **全局对象不跑构造函数**：全局变量只发射 `.quad {整型初值}`（整型字面量 / bool 字面量）或 `.quad 0`（其它一律零初始化），**不生成 .init_array**，也没有全局构造顺序机制。
- **不做异常展开信息**：不发射 `.eh_frame` / unwind table。
- **不做栈帧的 16 字节 ABI 对齐**：帧大小按 8 字节粒度分配（`subq $N, %rsp` 的 N 由 estimateFrameSize 给出）。

## §5 观测点（日志键）

**本模块不打日志**——src/codegen/codegen.cpp 里零 `std::cout`，发射过程完全静默。

★ 汇编产物的可观测手段是**逐字节比对**：

| 观测手段 | 内容 |
|---|---|
| logdiff 基线 | 每个集成用例的 .s 全文入基线；任何发射改动都会显形为字节差异 |
| tests/unit/test_codegen_frame.cpp | 断言不变量「帧 N ≥ 最深 -X(%rbp)」（learn/24 修的帧浅 bug） |
| tests/unit/test_symbol_consistency.cpp | 断言不变量「每个 callq 目标都有 .globl 定义」——命名规则随便改都不会误报 |
| tests/unit/test_vtable_symbols.cpp | 断言不变量「每条 `.quad <sym>` 都有 `.globl <sym>` 定义」 |

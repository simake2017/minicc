## 核心机制与判据

- **栈机式表达式求值**：操作数 push、运算符 pop 两数算完 push 回——与 AST
  的后序遍历天然同构。类型与字段名到此彻底消失，只剩地址和数字。
- **帧布局不变量**（learn/24 修的 bug）：estimateFrameSize 必须算上"帧基 +
  形参 spill 槽"，否则最深的局部落在 rsp 之下被 pushq/callq 踩掉（症状：
  变量单独读对、参与二元表达式就错）。test_codegen_frame.cpp 断言
  「帧 N ≥ 最深 -X(%rbp)」。
- **符号拼装全部过 asmSymbol**：命名空间类的 ctor/dtor、vtable 条目都不能
  在汇编期留下 junk。★ 消费点优先用 Sema 的**回填槽**（resolvedCalleeSymbol
  等），空才退回硬拼——mangling 是有状态的，CodeGen 不知道重载后缀。
- **类对象路径**：构造升级（VarDeclStmt 走 ctorSymbol）、平凡拷贝判据
  （equals，不看穿 const 会静默退化成默认构造——stripTopCvRef 判据归一）。
- **数组与下标**（learn/42）：数组名向首元素地址退化（VarExpr/MemberExpr
  统一 leaq），IndexExpr 读与 AssignStmt 写用 SIB 寻址（leaq (%rcx,%rax,scale)）。
- **控制流降级**（learn/38、41）：for 五标签、m_loopStack 保证 continue
  落【增量步】不落条件式；?: 短路两行条件跳转；switch 比较链 + fall-through。
- **vtable/RTTI 数据段**：槽符号与定义点同源（memberMethodSymbolName 单点，
  B20）；次基类槽原样透传上游符号，真覆写才改指本类实现 + thunk。

# 03.3 类与模板声明解析 —— 类体循环与模板头

> 上级：[00-总览](00-总览.md)。

## 管什么 / 不管什么

- 管：class/struct 定义体、继承说明符（默认 public，[class.derived]/2）、
  模板头四种形参（类型 `class T`、NTTP `int N`、`template<auto V>`、模板模板
  `template<class> class C`）、推导指引 `Box(T) -> Box<T>;`。
- 不管：成员的语义注册（Sema Pass 1）；模板实参的**语义**校验（Sema
  checkTemplateArguments）。

## 关键判据

- **类体方法/字段判定**：TokenCheckpoint 纯试探（永不 commit），消掉手写前瞻
  复制品。这是 parser.cpp 最后一个收口的试探点（B36 批次）。
- **成员模板说明符位置**（B19）：`template<...> static U f(U)` 标准写法在吃完
  形参表后**再认一次** static（收下）；virtual 当场报错（[temp.mem]/2：成员函数
  模板不得 virtual，文案逐字同 clang）。★ 「先声明」与「先出现」是两件事。
- **只做成员函数模板**：成员类模板/成员别名模板/静态数据成员模板在此响亮拒收。
- **推导指引前瞻**：`MyPtr(T)` 与 `MyPtr f(T)` 前两个 token 完全相同——靠
  "配对右括号后是否跟 `->`" 区分；looksLikeDeductionGuide 是纯 token 检查，
  不打日志（const 方法无试探日志，B36 判定不动它）。
- **模板形参表四种形参**的语法归一：parseTemplateDecl 从仅类模板分支扩到
  NTTP/ttp/auto（learn/33、35）；形参表内的 template 头照常收集进名字登记表。

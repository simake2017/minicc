# 03.5 名字识别 —— 名字登记表（parser 侧语义识别）

> 上级：[00-总览](00-总览.md)。对应 spec：docs/specs/parser-stage-name-recognition.spec.md（已签字）。

## 管什么

解析期"这个名字是什么种类"的**唯一判定依据**。`NameClassification` 四位并集：
`{isType, isNamespace, isTemplate, isValue(恒 false 占位)}`，键 = (scope, name)。
对齐 clang `Sema::ClassifyName`（SemaDecl.cpp:912）。

## 核心判据

- **分层红线**：Parser 只持构造期**前向收集的只读投影**，不持 Sema 活句柄——
  用空间（一份冗余账本）换架构分层（spec 否决记录，唯一权威表述）。
- **前向而非边解析边登记**：支撑先使用后声明；扫描循环不跳已处理区间。
- **收集规则**（5 条）：template 头后名字收 template 位（**不置 type 位**——
  `Box;` 对类模板名保持非类型解释）；struct/class/enum 名收 type 位；
  typedef 取末段标识符；`using X =`（Ident+Assign 形）；`namespace X {`
  推作用域栈按花括号深度配对 + `namespace A = B;`。种子名单收 Sema 内建
  `std::declval`（不经 token 流，构造时注入）。
- **同名跨类并存**：位按 (scope,name) 并集累积——`int S; struct S;` 合法。
- **签名规则（防错铁律）**：消费点只依赖**位命中**做正向判定；查不到 = 未知 =
  全 false，**禁止反向推断**（"查不到 ⇒ 不是"是这类消歧最常见的错法，learn/47 §6）。

## 消费点（4 个）

| 消费点 | 判定 |
|---|---|
| 语句层裸名 `S;` | type 位命中 ⇒ 判声明（新日志 `[parse:stmt]`） |
| 表达式模板闸 | isTemplate 命中才进试探 |
| 语句层模板 id 链闸 | 链上任一层基名未命中 ⇒ 推翻声明解释（→ 03.4） |
| Sema 限定模板名裁决 | classifyQualified 精确作用域：N::B 不存在**不再误绑全局 B**，报错与 clang 逐字 |

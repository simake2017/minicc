## §2 关键判据（详细设计）

- **宏表**：`#define` 对象宏 / 函数宏；查表替换在输出前逐行进行。内建静态宏
  `__MINICC__` 由构造函数直接注入（[cpp.predefined] 的 minicc 扩展）。
- **动态宏** `__LINE__` / `__FILE__` 与静态宏走不同路径：前者就地生成，后者只是表里的普通条目。
- **三条求值路径**（learn/37）：`#ifdef` 查 count；`#if __MINICC__>=1` 经常量表达式
  求值（第②步宏展开）；`defined()` 第①步单独处理。
- **#include 搜索**：引号形先查当前文件目录、再查 -I 路径；ministl 双栖桩头用
  引号 include 完整路径，**不在 -I 目录造叫 `cstddef` 的文件**（会连 clang 一起劫持）。
- **#pragma once**：按已解析绝对路径去重。
- **统计口径**：`userMacroCount()` 剔除内建名单，否则每个 TU 的宏计数恒 +1、日志基线漂移。

## §3 诊断类别（异常处理）

全部诊断走 `src/lex/preprocessor.cpp` 的唯一出口 `ppError()`，输出形态
`[Preprocessor Error] {文件}:{行号}: {文案}`。编译期诊断一律**不可重试**。

| # | 触发情形 | 诊断文案 | 可重试 |
|---|---|---|---|
| 1 | `#define` 缺宏名 | `macro name missing in #define` | 否 |
| 2 | 函数宏形参表里没有参数名 | `expected parameter name in #define` | 否 |
| 3 | 函数宏形参表分隔符不是 `,` 或 `)` | `expected ',' or ')' in macro parameter list` | 否 |
| 4 | `#include` 后缺文件名 | `expected filename after #include` | 否 |
| 5 | `#include "..."` 缺闭引号 | `unterminated " in #include` | 否 |
| 6 | `#include <...>` 缺闭尖括号 | `unterminated < in #include` | 否 |
| 7 | `#include` 的头名既不是 `"file"` 也不是 `<file>` | `expected "file" or <file> after #include` | 否 |
| 8 | `#include` 绕回正在展开的文件（无限递归） | `circular #include detected: {名}` | 否 |
| 9 | `#if` 表达式里有无法识别的 token | `unexpected token '{token}' in #if expression` | 否 |
| 10 | `#if` 表达式括号不配对 | `expected ')' in #if expression` | 否 |
| 11 | `#if` 表达式提前到头 | `unexpected end of #if expression` | 否 |
| 12 | `#if` 表达式里除以零 | `division by zero in #if` | 否 |
| 13 | `defined` 后缺标识符 | `expected identifier after 'defined'` | 否 |
| 14 | `defined(名` 缺右括号 | `expected ')' after defined(name` | 否 |
| 15 | 函数宏调用的实参表未闭合 | `unterminated argument list invoking macro '{名}'` | 否 |
| 16 | 函数宏调用的实参个数与形参表不符 | `macro '{名}' expects {n} argument(s), got {m}` | 否 |
| 17 | `#elif` 没有对应的 `#if` | `#elif without #if` | 否 |
| 18 | `#else` 没有对应的 `#if` | `#else without #if` | 否 |
| 19 | `#else` 重复出现 | `duplicate #else` | 否 |
| 20 | `#endif` 没有对应的 `#if` | `#endif without #if` | 否 |
| 21 | 条件编译块没有闭合 | `unterminated conditional directive ({n} open)` | 否 |
| 22 | `#error` 指令 | `#error ` + 指令原文 | 否 |
| 23 | 打开源文件 / 头文件失败 | `Cannot open file: {路径}` | 否 |

★ **警告不属诊断**（不中断编译、退出码仍为 0）：`warning: redefining macro '{名}'`、
`warning: unsupported #pragma {名} ignored`、`warning: unknown directive '#{名}' ignored`。

## §4 Out of Scope（本模块不做的事）

- **`#pragma` 只实现 `once`**：其余 pragma 一律打 `warning: unsupported #pragma {名} ignored` 后忽略，**不中断编译**（src/lex/preprocessor.cpp 的 handlePragma）。
- **不做 `#include_next` / `__has_include` / `#line` / `#warning`**：未知指令走 `warning: unknown directive '#{名}' ignored` 静默跳过。
- **不做宏的 `#` 字符串化与 `##` 拼接**（[cpp.replace]）：函数宏只做形参替换。
- **`#if` 只支持整数常量表达式子集**：优先级为 `|| < && < == != < < > <= >= < + - < * / < 一元 ! -`；**不做** `%`、位运算 `& | ^`、移位、三元 `?:`、字符字面量与浮点。`[cpp.cond]` 规定"剩余标识符 → 0"，本实现照此（`#if UNDEFINED_MACRO` 求值为 0）。
- **内建宏只有三个**：`__MINICC__`（静态注入）、`__LINE__`、`__FILE__`（动态就地生成）；**不注入** clang 那套版本/target 宏。
- **不做预置头 / 模块**：没有 `-include`、没有 `-fmodules`；搜索路径只有引号形（当前文件目录 → `-I` 目录）与尖括号形（`-I` 目录）。

## §5 观测点（日志键）

| 时机 | 打的键 |
|---|---|
| 进入预处理（主文件） | `[pp] preprocessing main file: {路径}` |
| 宏展开后逐行回吐 | `[pp] {文件}:{行号} [src-line] <SRC>{行}</SRC>` |
| 条件编译分支裁决 | `[pp] {文件}:{行号} #{指令} {条件} → branch {taken/skipped}` |
| 对象宏 / 函数宏登记 | `[pp] {文件}:{行号} #define {名} = {体}` / `[pp] {文件}:{行号} #define {名}({形参}) = {体}` |
| 宏撤销 | `[pp] line {行号} #undef {名}` |
| `#include` 解析结果 | `[pp] #include {名} → {路径}` |
| `#pragma once` 命中去重 | `[pp] #include {名} → skipped (pragma once)` |
| `#pragma once` 登记 | `[pp] {文件}:{行号} #pragma once → registered {路径}` |
| 宏重定义警告 | `[pp] {文件}:{行号} warning: redefining macro '{名}'` |
| 未知 pragma 警告 | `[pp] {文件}:{行号} warning: unsupported #pragma {名} ignored` |
| 未知指令警告 | `[pp] {文件}:{行号} warning: unknown directive '#{名}' ignored` |
| 动态宏就地生成 | `[pp] builtin __LINE__ → {行号}` / `[pp] builtin __FILE__ → "{文件}"` |
| 宏展开的逐步轨迹（内层） | `[pp] {文件}:{行号} │ object-macro {名} → body=[{体}]` / `[pp] {文件}:{行号} │ func-macro {名} body before=[{前}] → after=[{后}]` / `[pp] {文件}:{行号} │ final-substitution → [{结果}]` |

## §2 关键判据（详细设计）

- **不依赖系统 ld / crt / libc**：借系统 `as` 把 .s 汇编成 .o，之后合并节、
  符号决议、重定位回填全部自研。内置 `_start` 入口 + 64KB bump 分配器的
  malloc/free。
- **五步流水线**（与 learn/15 一一对应）：解析 ELF 头与节表 → 合并同类节 →
  符号决议（全局符号跨 .o 对齐地址）→ 重定位回填（R_X86_64_PC32/PLT32/64）→
  写可执行文件头与程序头。
- **非 PIE**：加载地址固定，重定位可按绝对地址直接算，免掉 GOT/PLT 一族复杂度
  ——这是教学取舍，换来"Hello World 从头到尾全是自己的代码"。
- **链接期即验收**：undefined reference 在这是最后防线——CodeGen 符号拼错
  （历史上 B10/B20/B22 全是这类）编译期全绿、唯独这里响亮报错。

## §3 诊断类别（异常处理）

链接失败由 `src/link/linker.cpp` 写进 `LinkResult::errorMsg`，驱动层打成
`[LINK ERROR] {文案}`（src/driver/main.cpp）。编译期诊断一律**不可重试**。

| # | 触发情形 | 诊断文案 | 可重试 |
|---|---|---|---|
| 1 | 目标文件读不出来 | `无法读取目标文件: {路径}` | 否 |
| 2 | 输入不是 ELF 文件 | `{路径}: 不是 ELF 文件` | 否 |
| 3 | 输入不是 ELF64 x86-64 可重定位文件（ET_REL） | `{路径}: 需要 ELF64 x86-64 可重定位文件(ET_REL)` | 否 |
| 4 | 同一个全局符号被定义两次 | `符号重复定义: '{符号}'` | 否 |
| 5 | 符号引用找不到定义 | `undefined reference to '{符号}'` | 否 |
| 6 | 可执行文件里没有 `main` | `undefined reference to 'main'（可执行文件需要 main 函数）` | 否 |
| 7 | 重定位指向的节不是可合并节 | `重定位目标节（索引 {n}）不是可合并节` | 否 |
| 8 | 重定位的符号索引越界 | `重定位符号索引越界` | 否 |
| 9 | 重定位引用的符号未定义 | `重定位引用未定义符号 '{符号}'` | 否 |
| 10 | 重定位的符号解析不到合并后的段 | `重定位符号 '{符号}' 无法解析到合并段` | 否 |
| 11 | `R_X86_64_32S` 重定位溢出 | `R_X86_64_32S 重定位溢出（值超出 32 位有符号范围）` | 否 |
| 12 | 不支持的重定位类型 | `不支持的重定位类型 R_X86_64_{类型}` | 否 |
| 13 | 输出文件写不出去 | `无法写入输出文件: {路径}` | 否 |
| 14 | 上游的汇编器 `as` 失败 | `[ERROR] 汇编失败 (as 退出码 {码})`（驱动层，src/driver/main.cpp） | 否 |

★ 第 5 条是**最后一道防线**：CodeGen 符号拼错（历史上 B10 / B20 / B22 全是这类）
在编译期全程绿灯，唯独在这里响亮报错。

## §4 Out of Scope（本模块不做的事）

- **不做 PIE**：加载地址固定，可执行文件是 ET_EXEC（这是教学取舍，换来免掉 GOT/PLT 一族复杂度）。
- **不做动态链接**：不处理 `.dynamic` / `.dynsym` / PLT / GOT，只做**静态**链接（输入 .o 子集）。
- **不做共享库输出**（`.so`）：只产出可执行文件。
- **只合并四个节**：`.text` / `.rodata` / `.data` / `.bss`（src/link/linker.cpp 的 kMergeNames）。**不做** COMDAT / `.group` 的去重合并，**不做** `.init_array` / `.fini_array`（因此全局对象的构造函数不会被调用）。
- **不做 TLS（thread-local storage）**：`.tbss` / `.tdata` 不在合并名单里。
- **不做符号版本**（`.gnu.version`）与弱符号（`WEAK`）的完整语义。
- **运行时不依赖 libc**：只有内置 `_start` + 64KB bump 分配器的 malloc/free——没有 `printf`、没有 `exit` 之外的运行时设施。

## §5 观测点（日志键）

| 时机 | 打的键 |
|---|---|
| 读入一个目标文件 | `[link] 读入 {路径}: {n} 个符号, {m} 条重定位, 合并节: {节名列表}` |
| 段布局确定 | `[link] 段布局: .text @ {地址} ({n}B) \| .rodata @ {地址} ({n}B) \| .data @ {地址} ({n}B) \| .bss @ {地址} ({n}B)` |
| 注入运行时（`_start` / `malloc` / `free`） | `[link] 注入运行时: _start @ {地址} \| malloc @ {地址} (bump) \| free @ {地址} (nop)` |
| 堆 arena 分配 | `[link] 堆 arena: {起址} ~ {止址} ({n}KB bump 分配)` |
| 符号决议完成 | `[link] 符号决议: {n} 个全局符号, main @ {地址}` |
| 重定位回填完成 | `[link] 重定位回填: {n} 条 ({统计})` |
| 可执行文件写出 | `[link] 写出 ELF: {路径} ({n}B, entry={地址}, RX段 {n}B / RW段 {n}B)` |

## 核心机制与判据

- **哲学**：编译期看"符号"（类型名/字段名），运行期看"偏移量"——本阶段就是把符号变成偏移量。
- **三遍扫描**：Pass 1 注册类/模板/静态成员 → Pass 2 注册函数名 → Pass 3 分析函数体。
  支持先使用后声明的关键。★ Pass 2/3 扁平遍历曾漏命名空间（CodeGen 收不到方法）——
  现在统一走 forEachFunctionDecl 递归原语。
- **类布局**：字段偏移（含多继承子对象偏移 = viaBase + baseFieldIndex 两级）、
  vtable 槽（主基类 primary 只在动态基类里选；无动态基类时 vptr 自己占 0）、RTTI。
- **成员查找收口**：`findMethodInHierarchy` / `findField` / `resolveQualifiedField`
  三个原语单点判据——同一判据不许写两份（B10/B22/B24 的共同教训）。查找按
  **裸名**（declaredName），显示名只是给人看的；★ **名字是给人看的，位置才是机器要的**。
- **隐藏与可行性正交**：查到名字就下结论（个数区外 too few/too many，区内
  no matching member），不往基类走——隐藏按名字、可行性按类型，两个正交筛选。
- **重载与身份**：身份 = 名字 + 形参类型链（paramTypeChain），择优原语
  pickBestByArgs（精确 → 可隐式转换 → 无可行候选报错）。vtable 槽符号与定义点
  共用 memberMethodSymbolName 单点定名。
- **编译期常量表**（主线 D）：const/constexpr 整型家族 + 初始化式可常量求值才登记，
  形态取声明类型；两条消费路径：常量传播（ConstantFolder 回调）与 NTTP 实参重解。
- **引用绑定判据**（B26）：referenceBindsValueCategory 全项目单点；`const T&` 拒
  右值、左值模型含 `*p` 与 `v[i]`（值类别按标准，不按节点种类猜）。

## §2 关键判据（详细设计）

- **哲学**：编译期看"符号"（类型名/字段名），运行期看"偏移量"——本阶段就是把符号变成偏移量。
- **三遍扫描**：Pass 1 注册类/模板/静态成员 → Pass 2 注册函数名 → Pass 3 分析函数体。
  支持先使用后声明的关键。★ Pass 2/3 扁平遍历曾漏命名空间（CodeGen 收不到方法）——
  现在统一走 forEachFunctionDecl 递归原语。
- **类布局**：字段偏移（含多继承子对象偏移 = viaBase + baseFieldIndex 两级）、
  vtable 槽（主基类 primary 只在动态基类里选；无动态基类时 vptr 自己占 0）、RTTI。
- **成员查找收口**：`findMethodInHierarchy` / `findField` / `resolveQualifiedField`
  三个原语单点判据——同一判据不许写两份（B10/B22/B24 的共同教训）。查找按
  **裸名**（declaredName），显示名只是给人看的；★ **名字是给人看的，位置才是机器要的**。
- **隐藏与可行性正交**：查到名字就下结论（个数区外 too few/too many，区内
  no matching member），不往基类走——隐藏按名字、可行性按类型，两个正交筛选。
- **重载与身份**：身份 = 名字 + 形参类型链（paramTypeChain），择优原语
  pickBestByArgs（精确 → 可隐式转换 → 无可行候选报错）。vtable 槽符号与定义点
  共用 memberMethodSymbolName 单点定名。
- **编译期常量表**（主线 D）：const/constexpr 整型家族 + 初始化式可常量求值才登记，
  形态取声明类型；两条消费路径：常量传播（ConstantFolder 回调）与 NTTP 实参重解。
- **引用绑定判据**（B26）：referenceBindsValueCategory 全项目单点；`const T&` 拒
  右值、左值模型含 `*p` 与 `v[i]`（值类别按标准，不按节点种类猜）。

## §3 诊断类别（异常处理）

本域的诊断全部由 `src/sema/semantic_analyzer.cpp` 的 `error()` 打出，输出形态
`[Semantic Error] {行:列}: {文案}`。编译期诊断一律**不可重试**。

| # | 触发情形 | 诊断文案 | 可重试 |
|---|---|---|---|
| 1 | 名字在作用域链与全局都查不到 | `Undefined variable '{名}'` | 否 |
| 2 | 类里没有这个成员 | `No member '{名}' in class '{类名}'` | 否 |
| 3 | 多继承里同名字段在两个基类子对象中都有 | `Member '{名}' is ambiguous in class '{类名}': found in {n} base-class subobjects ({列表})` | 否 |
| 4 | 自由函数调用：没有任何候选可行 | `no matching function for call to '{名}' — {原因} ('{实参类型}')` | 否 |
| 5 | 初始化式类型与声明类型不符 | `Type mismatch in '{名}': declared '{声明类型}', got '{实际类型}'` | 否 |
| 6 | `constexpr` 变量的初始化式不可常量求值 | `constexpr variable '{名}' must be initialized by a constant expression` | 否 |

★ 逐条的完整清单见 01~06 六份子文档各自的 §3；**模板实参校验**（`class template '...' expects at most ...`）
归 05 模板域。

## §4 Out of Scope（本模块不做的事）

- **本页是索引页，不承载判据细节**：六份子文档（01~06）各自负责一块，本页只做"子文档导航 + 机制总表"。
- **不含模板推导与实例化**：那些在 05 模板域（本页的 §2 里点到的 `deducePair` / `substituteType` 只是指针）。
- **不含代码生成**：偏移量怎么变成指令在 06 域；本域只**算**偏移量，CodeGen 只读。
- **不含端到端走线**：跨层的调用链归 `docs/lines/**`。
- **不含变更计划**：一次改动怎么做归 `docs/specs/**` + `docs/designs/**`。
- **不做错误恢复**：语义错误一律 fail-fast（遇第一个即终止），不做 clang `DiagnosticsEngine` 那种"跳过错误继续收集"。

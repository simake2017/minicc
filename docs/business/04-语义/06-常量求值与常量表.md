## §1 管什么（定位）

const/constexpr 整型家族变量的**编译期值表** m_constValues 及其两条消费路径。

## §2 关键判据（详细设计）

- **登记判据单点** registerConstVar：const/constexpr + 整型家族 + 初始化式可
  常量求值；**形态取声明类型**——`constexpr long k=5` 的 k 是 long，
  K<k> ⇒ K<5:long>（形态丢了就静默撞键）。
- **constexpr 是义务不是优化**（[dcl.constexpr]/9）：初始化式不可求值 ⇒ 报错
  与 clang 逐字同（"must be initialized by a constant expression"）。
- **只登记整型家族** ⇒ 指针 const 不进表；**地址边界**：折叠只收 Neg/Not，
  `&b`/`*p` 子树原样保留（折成字面量会生成野地址）。
- **消费路径① 常量传播**：ConstantFolder 经 setConstResolver 回调把 VarExpr
  替换成字面量——回调分层与 Instantiator 三个求值器**第四次同形状**；
  ★ 类作用域回查：ReturnStmt 先 fold 后 infer，成员函数裸名折叠时还没改名，
  constResolver 补 BFS。
- **消费路径② NTTP 实参重解**：`Buf<k>` 裸名字实参在 resolveType 该位形参是
  NTTP 时查表改写成值实参，与 `Buf<5>` 同形同缓存键；查不到维持响亮报错。
- **求值双返回** evaluateIntegral：(值, 形态)——auto 形参 K<2+2> 与 K<4L>
  是两个实例。

## §3 诊断类别（异常处理）

本模块的诊断由 `src/sema/semantic_analyzer.cpp` 的 `error()` 打出，输出形态
`[Semantic Error] {行:列}: {文案}`。编译期诊断一律**不可重试**。

| # | 触发情形 | 诊断文案 | 可重试 |
|---|---|---|---|
| 1 | `constexpr` 变量的初始化式不可常量求值（[dcl.constexpr]/9 的强制义务） | `constexpr variable '{名}' must be initialized by a constant expression` | 否 |
| 2 | `case` 的值不是常量表达式 | `case value is not a constant expression` | 否 |
| 3 | 数组长度不是常量表达式 | `array size is not a constant expression` | 否 |
| 4 | 数组长度求值后 ≤ 0 | `array size must be greater than zero, got {值}` | 否 |
| 5 | static 成员的初始化式不是常量表达式 | `static member '{名}' initializer is not a constant expression` | 否 |
| 6 | NTTP 实参是常量表达式但求值失败 | `non-type template argument is not a constant expression` | 否 |

★ 第 1 条与 clang++-18 **逐字相同**（clang 原文：`constexpr variable 'm' must be initialized
by a constant expression`）。它是**强制义务不是优化**——不可求值就是错误。
★ 第 6 条与 clang **逐字相同**（负向用例 `Buf<1/0>`：除零不折 + 求值器见非字面量树）。

## §4 Out of Scope（本模块不做的事）

- **不做 constexpr 函数**：只做 constexpr **变量**（learn/40 的边界）。
- **不做 `if constexpr`**：分支不做编译期求值，两支都会进 AST。
- **不做 `consteval` / literal type 判定**：不区分"必须在编译期求值"与"可以运行期求值"。
- **折叠只收 Neg / Not 一元运算**：`&b` / `*p` 子树原样保留——折成字面量会生成野地址（learn/40 的地址边界）。
- **常量表只登记整型家族**：指针 const 不进表（登记了也没法折）。
- **常量表无作用域链**：内层覆盖外层；同命名空间的回退是**取舍**不是实现（learn/40 登记的边界）。
- **不做常量折叠的传播到数组下标 / switch 标签以外的场景**：目前只有 6 个 fold 钩子（初始化式 / return / 表达式语句 / 三处条件）。

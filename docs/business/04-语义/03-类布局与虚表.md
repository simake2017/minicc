# 04.3 类布局与虚表 —— 偏移与槽位的决议

> 上级：[00-总览](00-总览.md)。

## 管什么

ClassLayout：字段偏移、vptr 位置、vtable 槽表、RTTI。Sema 计算，CodeGen 只读。

## 关键判据

- **字段定位三级**（B13~B15）：`子对象偏移(viaBase) + 基类布局[baseFieldIndex].offset`。
  FieldInfo 三字段各司其职：declaredName（权威裸名，查找的键）/ viaBase（装着它的
  **直接**基类子对象）/ baseFieldIndex（基类布局里的下标）。★ **显示名曾兼任
  索引，是 B13~B15 同根缺陷**——名字是给人看的，位置才是机器要的。
- **primary 基类三态**（B11）：动态基类里选 primary 摆到 0；一个都没有时
  **vptr 自己占 0**、基类从 8 起。旧判据只写两态 ⇒ 本类自己的 _vptr 与首基类
  撞 0，写基类字段即写坏虚表指针、虚调用跳飞 SIGSEGV（真 miscompile）。
- **vtable 符号单点定名** memberMethodSymbolName(owner, name, paramCount,
  earlierSameNameCount)（B20）：registerFunction 与 vtable 三个落点（主表覆写/
  次表覆写/新条目）共用。**计数口径有坑**：只数排在当前方法**之前**的同名方法。
- **次基类槽原样透传**（B20 缺陷②）：未覆写的槽保留上游符号（X_f），**不**按
  "这条槽属于 Q"重造 Q_f——重造即链接期 undefined reference。
- **槽位认领按签名**（B22）：`virtual int f(); int f(int);` 里非虚的后者曾认领
  前者的槽并被误标 virtual（运行返回 255 的静默算错）——身份 = 名字 + 形参
  类型链。
- **static 成员不进布局**：挂在类名上的全局变量，类内声明 + 类外定义出存储；
  漏定义 odr-use ⇒ 链接期响亮报错（learn/44）。

# 04.1 类型系统 —— Type 结构、同一性、cv 位置

> 上级：[00-总览](00-总览.md)。

## 管什么

编译期类型的**值语义**表示：Type 节点树（Basic/Pointer/LValueRef/Const/Class/
TemplateParam/Array…）。运行期只有宽度（sizeInBytes）和地址。

## 关键判据

- **equals 是同一性判据**：类型缓存键、mangling、平凡拷贝判据全吃它。★
  `toString()` **不是单射**（`Const(Pointer(Int))` 与 `Pointer(Const(Int))` 都印成
  `const int*`）——拿给人看的串当机器键，早晚出事（learn/23；实例缓存键已改
  lossless 版，05.2）。
- **cv 位置精确**（learn/23）：`const int*` = Pointer(Const(Int))；
  `int* const` = Const(Pointer(Int))；`const int&` = LRef(Const(Int))。
  ★ cv 位置一改，所有"按旧形态看类型"的地方都要重看一遍（B26 的 const 剥除
  分支就是踩了这个）。
- **可表示性收口** canRepresentValue（B17）：NTTP 实参判据不是"形态精确相等"
  （会拒收 `Flag<1>`、`A<4L>` 合法程序），而是 [temp.arg.nontype]/1 → [expr.const]/10
  → [dcl.init]/7 的**值可表示**；通过后**形态归一**（a.valueType = p.nonType），
  `Buf<4L>` 与 `Buf<4>` 才是同一实例。
- **谓词族**：isInteger/isChar/isUnsignedInteger/integerBitWidth；sizeInBytes
  从位宽**推导**（一处真源，不再两处各写一份）——CodeGen 按宽度分派、零
  TypeKind 引用，新标量类型的代码生成成本为 0。
- **stripReferences/stripConst** 只服务类性/族性判定；标量路径、日志、符号表
  里的原 type 不动（非 const 程序汇编逐字节不变，B34）。

## 二、全局红线（本项目版，逐条来自事故）

1. **语法期零语义分层**：Parser 只许持「构造期前向收集的只读名字投影」，
   禁止持 Sema 活句柄、禁止查活符号表（[stmt.ambig] 分层，B16/B21；
   2026-10-23 用户拍板维持，否决理由见 specs/parser-stage-name-recognition
   否决记录）。
2. **宁宽勿窄**：消歧判据误收 → TokenCheckpoint 试探回退、响亮拒收；
   漏收 → 方向性错（B31）。宁可多试探，不可漏收。
3. **判据单点**：同一语义判据禁止写两处（B10 符号 / B13~B15 布局 /
   B22 身份的重灾区：两处必不一致，且错误总停在链接期）。
4. **日志即契约**：单测靠子串匹配日志原文、docs/learn 直接粘贴日志片段。
   任何改动必须 `./logdiff.sh diff` 零漂移；**有意漂移显式列出并重刷基线**。
   基线会把**失败**也固化成契约——修完必须回头看 rc，不能只看零差异（三次教训）。
5. **回归红线**：`test_tmpl_01..10` 永远全绿；「完成」= `./build.sh` 0 警告 +
   `ctest --test-dir build-linux -j6` 全绿 + logdiff 零差异，三件套缺一不算。
6. **诊断文案**：负向用例的期望报错与 `clang++-18` **逐字对齐**（含位置）。
7. **突变验证**：新判据必须配「摘掉判据 ⇒ 测试变红」的负向验证；
   恢复用 **cp 备份**，严禁 `git checkout` 未提交文件（B34 批次教训）。
8. **交付三件套**：每个子阶段产出 代码（README 语法表 → Ast/Parser → Sema →
   新模块 → CodeGen → tests 固定顺序）+ `docs/learn/NN-主题.md`
   （理论背景点名标准章节 + clang 源码对照表 + 可复现实验 + ASCII 图）
   + 测试（文件头写预期行为与考察理论点）。流水线的 specs/designs 是
   **流程产物**，learn 是**学习产物**，两者互补不互替。

## 三、结构约束（目录与分层）

```text
docs/constraints/   流程约束（本目录，唯一权威）
docs/specs/         场景 spec（每场景一份，人签字；未签字禁止写代码）
docs/designs/       技术开发设计（签字后起草，逐条映射回 spec 条款）
docs/learn/NN-*.md  学习文档（交付三件套之一，照 CLAUDE.md 规范）
include/            契约：类型 + 常量 + 语义注释（钉死空值语义/谁写谁读），不放逻辑
src/                实现：代码结构对齐 clang 的对应功能位置，内部自由
tests/              集成用例（tests/lang tests/tmpl tests/mi tests/flow …）
tests/unit/         googletest 单测（断言不变量，不钉具体符号名/具体值）
```

- 不建 flows/ shared/ 聚合目录（用户拍板，见本文件头部）。
- 判据/编排散写到多处 = 打回（红线 3）。
- 契约改动 = 同步改注释语义 + 所有调用方 + spec 更新对照。
- 新业务 = 新 spec + 复用模块，不改老 spec 的已签字条款（变更流程：
  先回改 spec 版本行 → 人重新签字 → 设计映射表补行 → 再动代码）。

## 四、关键动作细节

每个业务在 `02-关键动作细节.md` 里加一节，三段式「怎么做 / 为什么 /
好处」。本项目首批（parser 消歧业务的通用细节）：

1. **怎么做**：试探一律走 TokenCheckpoint（RAII 快照 pos + stopAtGreater +
   日志缓冲栈），纯试探永不 commit、窄捕获 ParseError。**为什么**：试探日志
   留痕曾固化 14 行幽灵行进基线无人察觉。**好处**：回滚机制上不可能留痕。
2. **怎么做**：语义 oracle 先行——写任何用例/判据前，先 clang++-18 探针。
   **为什么**：三次把 minicc 的误拒当正确行为写进用例。**好处**：期望行为
   有权威出处，分歧当场暴露。
3. **怎么做**：日志键与文案改动按「有意漂移」流程显式申报。**为什么**：
   154 份基线是逐字节契约。**好处**：漂移可审计、可复核。
